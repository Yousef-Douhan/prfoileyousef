# 🚀 Personal Portfolio Website - Yousef Hassan Douhan

The professional personal portfolio and showcase website for **Yousef Hassan Douhan** — a Backend Developer specializing in **PHP & Laravel**.

---

## 🌟 Overview

An interactive and professional portfolio website designed specifically to showcase programming skills, engineering projects, and academic and professional certifications. Built with a modern, elegant design featuring a Modern Dark Mode and full support for theme switching and bilingual localization.

### ✨ Key Features:
- **Bilingual Support:** Instant and seamless switching between Arabic and English languages (RTL / LTR).
- **Dark & Light Mode:** A comfortable user experience with one-click color scheme toggling.
- **Fully Responsive Design:** Optimized for all screen sizes and devices (Desktop, Tablet, Mobile).
- **Interactive Code Preview:** A dedicated backend code display window inspired by the Laravel development environment.
- **Direct Communication Links:** Quick access for instant communication via WhatsApp, Email, and LinkedIn.

---

## 🛠️ Tech Stack

This repository is built using core frontend technologies:

- **HTML5:** For building the semantic and robust structure of the website (`index.html`).
- **CSS3:** For styling interfaces using CSS variables and engaging color palettes (`style.css`).
- **JavaScript (ES6+):** For handling real-time translation and user interactivity (`script.js`).
- **FontAwesome & Google Fonts:** For professional icons and typography (IBM Plex Sans Arabic & Plus Jakarta Sans).
